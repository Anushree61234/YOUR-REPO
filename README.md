# Stayora – Full-Stack Airbnb Clone

A feature-rich accommodation booking platform built with **Node.js, Express, MongoDB, and Tailwind CSS**.

## Features

- 🔐 **User Authentication** – Guest & Host signup/login
- 🏠 **Home Listings** – Hosts can add, edit, delete properties with images
- ❤️ **Favorites System** – Guests can save favorite homes
- 📅 **Booking System** – Date selection, conflict detection, host approval workflow
- ✅ **Status Tracking** – Pending, approved, rejected, cancelled bookings
- 📱 **Responsive Design** – Mobile-friendly UI with Tailwind CSS

## Tech Stack

- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Frontend:** EJS templates, Tailwind CSS
- **Auth:** express-session, bcryptjs, express-validator
- **File Upload:** Multer

## Installation

```bash
git clone https://github.com/Anushree61234/stayora.git
cd stayora
npm install
npm start
```

Visit `http://localhost:3000`
